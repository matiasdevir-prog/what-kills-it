# 🔥 What Kills It — *Qué la mata*

A **Claude skill** that grills your plan, idea, strategy, spec, or code **before you build it**.

Most AI tools cheer you on. This one doesn't. It interviews you, finds the holes,
forces an honest way to measure success, and names the **single thing most likely to
kill your idea** — so you fail cheap now instead of expensive later.

Ruthless on the work. Kind to the builder.

---

## What it does — the grill, in six passes

1. **Pin it down.** Makes you say *exactly* what you're building, with no weasel words. ("Better" isn't accepted: better than what, measured how?)
2. **Find the holes.** Hidden cost, cherry-picking, overfit / "works in the demo", missing edge cases, unstated assumptions, who already does this and why they haven't won.
3. **How will you KNOW?** Demands an honest test: a frozen metric chosen *before*, a baseline to beat, out-of-sample, net of real cost, measured in its real window — one honest number agreed in advance.
4. **¿Qué la mata?** Names the one failure that, if it happens, the whole thing is dead. Then the next two.
5. **The cheapest test.** The smallest experiment that proves-or-kills the top risk fast — a day, not a quarter.
6. **Verdict.** Go / No-go / Fix-first, in one line. No false encouragement.

It's **bilingual**: the engine is English, but it replies in whatever language you write in.

## Install

**Cowork (Claude desktop app):** open `what-kills-it.skill` and click **Save skill**.

**Claude Code / manual:** copy `SKILL.md` into a folder named `what-kills-it/` inside your skills directory (e.g. `~/.claude/skills/what-kills-it/SKILL.md`).

---

## Use it

Bring something you're about to build and say:

> *"Grill me on this."* · *"Destrozá mi plan."* · *"¿Qué la mata?"* · *"Find the holes in this before I build it."*

It activates on those automatically, or call it by name.

---

## The law behind it

This skill is one person's honest-measurement law turned into a tool:

- **Never sell hope.** If it probably won't work, say it — kindly, clearly, now.
- **Backtest ≠ live. Demo ≠ production. Said ≠ measured.**
- **One honest number** beats ten flattering ones.
- Your value as a person doesn't depend on whether the idea survives.
